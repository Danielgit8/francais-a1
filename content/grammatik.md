## 1. Aussprache, Alphabet, Buchstabieren

### Alphabet (Aussprache in deutscher Lautschrift)

| Buchstabe | spricht man | Buchstabe | spricht man |
|---|---|---|---|
| A | a | N | änn |
| B | be | O | o |
| C | se | P | pe |
| D | de | Q | kü |
| E | ö (kurz) | R | ärr |
| F | äff | S | äss |
| G | **schö** (wie „Garage“) | T | te |
| H | asch | U | ü |
| I | i | V | we |
| J | **schi** | W | dubbl-we |
| K | ka | X | iks |
| L | äll | Y | i-gräk |
| M | ämm | Z | sädd |

**Achtung für Deutsche:** G und J klingen fast umgekehrt wie erwartet: G = „sche“, J = „schi“. E = „ö“, I = „i“, U = „ü“.

### Beim Buchstabieren
| Französisch | Deutsch |
|---|---|
| **é** – e accent aigu | e mit Akut |
| **è** – e accent grave | e mit Gravis |
| **ê** – e accent circonflexe | e mit Zirkumflex |
| **ç** – c cédille | c mit Cedille (wird „s“ gesprochen) |
| **ë / ï** – e/i tréma | Trema |
| **deux l / deux s** | Doppel-l / Doppel-s |
| **majuscule / minuscule** | Groß- / Kleinbuchstabe |
| **le trait d'union (-)** | Bindestrich |
| **l'apostrophe (')** (f) | Apostroph |
| **arobase (@)** | at-Zeichen |
| **point (.)** | Punkt |
| **tiret (–) / tiret bas (_)** | Bindestrich / Unterstrich |

### Die wichtigsten Ausspracheregeln
- **Endkonsonanten** meist stumm: *petit, grand, vous, Paris*. Ausnahme häufig bei **c, r, f, l** (Merkwort „CaReFuL“): *avec, bonjour, neuf, il*. Bei *-er* am Verbende ist das r stumm: *parler*.
- **-e am Wortende** stumm: *table, rue*. **-ent** bei Verben (ils) stumm: *ils parlent* = „il parl“.
- **h** wird nie gesprochen: *l'hôtel, l'homme*.
- **Nasale:** *an/en* (*enfant*), *on* (*bonjour*), *in/ain/ein/un* (*vin, pain, un*).
- **Liaison** (Bindung): *les‿amis* („le-s-ami“), *vous‿êtes*, *ils‿ont* (z) ≠ *ils sont* (s), *un‿enfant*, *deux‿heures*.
- **Elision** (Apostroph vor Vokal/stummem h): *le → l'* (l'ami), *la → l'*, *je → j'* (j'aime), *ne → n'*, *de → d'*, *que → qu'*, *me/te/se → m'/t'/s'*, *si il → s'il*.
- **Typische Laute:** *ou* = u (*vous*), *u* = ü (*tu*), *oi* = wa (*moi*), *eau/au* = o (*beau*), *ai* = ä (*j'ai*), *eu* = ö (*deux*), *ch* = sch (*chat*), *gn* = nj (*champagne*), *ill* = j (*fille*), *qu* = k (*qui*), *c* vor e/i = s, sonst k, *g* vor e/i = sch, sonst g.

## 2. Nomen: Genus und Plural

### Genus
Jedes Nomen ist **maskulin oder feminin**. Immer mit Artikel lernen.

| Faustregel | maskulin | feminin |
|---|---|---|
| Endungen | -age (*le fromage*), -ment, -eau, -isme, -al | -tion/-sion (*la nation*), -té (*la santé*), -ette, -ure, -ence/-ance, -ie, -ine |
| Ausnahmen merken | *le lycée, le musée* (auf -e, trotzdem m.) | *la plage, la page, l'image (f), l'eau (f), la peau, la photo, la moto, la radio* (Kurzformen) |

### Personen und Berufe: männlich → weiblich
| Muster | Beispiel |
|---|---|
| + e | un ami → une ami**e**, un étudiant → une étudiant**e** |
| -en → -enne | un Italien → une Italie**nne** |
| -er → -ère | un boulanger → une boulang**ère** |
| -eur → -euse | un vendeur → une vend**euse** |
| -teur → -trice | un acteur → une ac**trice** |
| gleich | un/une élève, un/une journaliste, un/une secrétaire, un/une médecin |
| eigenes Wort | un homme / une femme, un père / une mère, un garçon / une fille |

### Plural
| Regel | Singular → Plural |
|---|---|
| Normalfall: **+ s** (nicht gesprochen) | le livre → les livre**s** |
| -s, -x, -z bleibt | le bus → les bus, le prix → les prix, le nez → les nez |
| -eau, -eu → **+ x** | le gâteau → les gâteau**x**, le cheveu → les cheveu**x** |
| -al → **-aux** | le journal → les journ**aux**, l'animal → les anim**aux** |
| unregelmäßig | l'œil → **les yeux**, madame → mesdames, monsieur → messieurs |

## 3. Artikel

### Übersicht
| | maskulin | feminin | vor Vokal / h | Plural |
|---|---|---|---|---|
| **bestimmt** (der/die/das) | le | la | l' | les |
| **unbestimmt** (ein/eine) | un | une | un / une | des |
| **Teilungsartikel** (etwas, unbestimmte Menge) | du | de la | de l' | des |

### Wann welcher Artikel?
| Situation | Artikel | Beispiel |
|---|---|---|
| Etwas Bestimmtes, Bekanntes | le / la / les | *La gare est là.* |
| Allgemeine Vorlieben (aimer, adorer, préférer, détester) | le / la / les | *J'aime **le** chocolat. Je déteste **les** chats.* |
| Eins von vielen, zählbar | un / une / des | *J'ai **un** frère et **des** amis.* |
| Unzählbare Menge (Essen, Trinken, Sport, Musik mit faire/jouer) | du / de la / de l' | *Je mange **du** pain. Je bois **de l'**eau. Je fais **du** sport.* |
| Wochentag regelmäßig | le | *Le lundi, je travaille.* (montags) |
| Datum | le | *le 14 juillet* |
| Länder | le / la / les | ***La** France, **l'**Allemagne, **le** Canada* |

### Verschmelzung mit à und de
| | + le | + la | + l' | + les |
|---|---|---|---|---|
| **à** | **au** | à la | à l' | **aux** |
| **de** | **du** | de la | de l' | **des** |

*Je vais **au** cinéma / **à la** gare / **à l'**hôtel / **aux** toilettes.*
*Je viens **du** travail / **de la** piscine. La porte **du** jardin.*

### Artikel wird zu „de / d'“
| Regel | Beispiel |
|---|---|
| Nach Verneinung (un/une/des/du/de la → **de**) | *J'ai un chien. → Je n'ai **pas de** chien.* / *Je bois du café. → Je ne bois **pas de** café.* / *Il n'y a **pas d'**eau.* |
| Ausnahme: nach *être* bleibt der Artikel | *Ce n'est pas **un** chat.* |
| Ausnahme: bei Vorlieben bleibt *le/la/les* | *Je n'aime pas **le** café.* |
| Nach Mengenangaben | *beaucoup **de** pain, un kilo **de** pommes, un peu **d'**eau* |

## 4. Adjektive

### Angleichung (an Genus und Zahl des Nomens)
| maskulin Sg. | feminin Sg. | maskulin Pl. | feminin Pl. | Regel |
|---|---|---|---|---|
| petit | petit**e** | petit**s** | petit**es** | Normalfall |
| jeune | jeune | jeune**s** | jeune**s** | endet schon auf -e |
| italien | italie**nne** | italien**s** | italie**nnes** | -en → -enne |
| bon | bo**nne** | bon**s** | bo**nnes** | -on → -onne |
| gentil | genti**lle** | gentil**s** | genti**lles** | -il → -ille |
| sportif | sporti**ve** | sportif**s** | sporti**ves** | -f → -ve |
| heureux | heureu**se** | heureux | heureu**ses** | -eux → -euse |
| cher | ch**ère** | cher**s** | ch**ères** | -er → -ère |
| blanc | blan**che** | blanc**s** | blan**ches** | unregelmäßig |
| long | lon**gue** | long**s** | lon**gues** | unregelmäßig |
| roux | rou**sse** | roux | rou**sses** | unregelmäßig |
| marron, orange | marron, orange | marron, orange | marron, orange | unveränderlich |

### Drei besondere Adjektive (eigene Form vor Vokal/h, nur maskulin Singular)
| m. | m. vor Vokal | f. | m. Pl. | f. Pl. |
|---|---|---|---|---|
| beau | **bel** (un bel homme) | belle | beaux | belles |
| nouveau | **nouvel** (un nouvel ami) | nouvelle | nouveaux | nouvelles |
| vieux | **vieil** (un vieil hôtel) | vieille | vieux | vieilles |

### Stellung
- **Normalerweise nach dem Nomen:** *une voiture **rouge**, un livre **intéressant**, un homme **sympa***. Farben und Nationalitäten immer danach.
- **Vor dem Nomen** stehen kurze, häufige Adjektive (Merkwort **BAGS**: Beauty, Age, Goodness, Size):
  *beau, joli, jeune, vieux, nouveau, bon, mauvais, grand, petit, gros, long, premier, dernier*
  → *une **petite** maison, un **bon** restaurant, une **jolie** robe, le **premier** jour*
- Plural vor Adjektiv: *des* → *de*: *de **jolies** fleurs* (in der Umgangssprache oft auch *des*). [A1/A2]

## 5. Possessivbegleiter (mein, dein …)

| Besitzer | vor m. Sg. | vor f. Sg. | vor Plural |
|---|---|---|---|
| je (mein) | mon | ma | mes |
| tu (dein) | ton | ta | tes |
| il / elle (sein/ihr) | son | sa | ses |
| nous (unser) | notre | notre | nos |
| vous (euer/Ihr) | votre | votre | vos |
| ils / elles (ihr) | leur | leur | leurs |

- Richtet sich nach dem **Besitz**, nicht nach dem Besitzer: *Paul aime **sa** mère. Marie aime **son** père.* (*son* = sein **oder** ihr)
- Vor feminin mit Vokal: **mon / ton / son** statt ma/ta/sa: ***mon** amie, **ton** adresse, **son** école.*
- Frage nach Besitz: *C'est à qui ? – C'est **à moi** / à Paul.* (Wem gehört das? – Mir / Paul.)

## 6. Demonstrativbegleiter (dieser, diese, dieses)

| m. Sg. | m. Sg. vor Vokal/h | f. Sg. | Plural |

## 7. Personalpronomen

### Subjektpronomen
| | Singular | | Plural |
|---|---|---|---|
| je (j') | ich | nous | wir |
| tu | du | vous | ihr / Sie (höflich, auch Einzahl) |
| il | er (auch „es“ unpersönlich) | ils | sie (männlich oder gemischt) |
| elle | sie | elles | sie (nur weiblich) |
| **on** | man / **wir** (umgangssprachlich, Verb wie il) | | |

*On va au cinéma ? = Gehen wir ins Kino?*
**tu oder vous?** *tu* mit Familie, Freunden, Kindern, Gleichaltrigen in lockerem Rahmen. *vous* mit Fremden, im Geschäft, mit Prüfern. Im Zweifel: *vous*.

### Betonte Pronomen
| moi | toi | lui | elle | nous | vous | eux | elles |
|---|---|---|---|---|---|---|---|
| ich/mich | du/dich | er/ihn | sie | wir/uns | ihr/euch/Sie | sie (m.) | sie (f.) |

Gebrauch:
- zur Betonung: ***Moi**, je m'appelle Anna. Et **toi** ?*
- nach Präposition: *avec **moi**, chez **toi**, pour **lui**, sans **eux***
- nach *c'est*: *C'est **moi**. C'est **lui**.*
- in Kurzantworten: ***Moi** aussi. **Moi** non plus. Et **vous** ?*
- *chez moi* = bei mir / zu mir nach Hause

### Reflexivpronomen (siehe Kap. 10)
me (m'), te (t'), se (s'), nous, vous, se (s')

### Objektpronomen [A1/A2]
Im A1-Alltag vor allem in festen Wendungen:
| Pronomen | Bedeutung | A1-Beispiel |
|---|---|---|
| le / la / l' / les | ihn / sie / es / sie (direktes Objekt) | *Le pull ? Je **le** prends. – La robe ? Je peux **l'**essayer ?* |
| me, te, nous, vous | mich/mir, dich/dir … | *Tu **m'**appelles ? Je **vous** remercie. Ça **me** plaît.* |
| lui / leur | ihm/ihr, ihnen | *Je **lui** téléphone.* |
| y | dort(hin) | ***On y va !** (Los geht's!) – **Il y a** …* |
| en | davon | *J'**en** prends deux.* |

Stellung: **vor** dem konjugierten Verb (*Je **le** prends*), beim Infinitiv vor dem Infinitiv (*Je vais **le** prendre*).

## 8. Verben im Präsens: regelmäßig

### Verben auf -er (ca. 90 % aller Verben) – Beispiel *parler* (sprechen)
| Person | Endung | Form | Aussprache |
|---|---|---|---|
| je | -e | je parl**e** | parl |
| tu | -es | tu parl**es** | parl |
| il/elle/on | -e | il parl**e** | parl |
| nous | -ons | nous parl**ons** | parlõ |
| vous | -ez | vous parl**ez** | parle |
| ils/elles | -ent | ils parl**ent** | parl |

→ Gesprochen nur **3 Formen**: parl / parlõ / parle.
Ebenso: *aimer, habiter, travailler, regarder, écouter, jouer, chanter, danser, manger, étudier, visiter, chercher, trouver, donner, demander, rester, arriver, entrer, rentrer, penser, téléphoner, commencer, préférer, acheter, appeler, payer, s'appeler, se lever* …

### Kleine Besonderheiten bei -er-Verben
| Verb | Besonderheit | Formen |
|---|---|---|
| manger (essen) | nous mit **-geons** | nous man**geons** |
| commencer (anfangen) | nous mit **-çons** | nous commen**çons** |
| acheter (kaufen) | è in betonter Silbe | j'ach**è**te, tu ach**è**tes, il ach**è**te, nous achetons, vous achetez, ils ach**è**tent |
| préférer (vorziehen) | è in betonter Silbe | je préf**è**re, nous préférons, ils préf**è**rent |
| appeler (rufen) / s'appeler | ll in betonter Silbe | je m'appe**ll**e, tu t'appe**ll**es, il s'appe**ll**e, nous nous appelons, vous vous appelez, ils s'appe**ll**ent |
| payer (zahlen) | y → i möglich | je pa**i**e / je paye, nous payons |
| envoyer (schicken) | y → i | j'envo**i**e, nous envoyons, ils envo**i**ent |

### Verben auf -ir mit -iss- – Beispiel *finir* (beenden)
je fin**is**, tu fin**is**, il fin**it**, nous fin**issons**, vous fin**issez**, ils fin**issent**
Ebenso: *choisir* (wählen), *remplir* (ausfüllen).

### Verben auf -re – Beispiel *attendre* (warten)
j'attend**s**, tu attend**s**, il attend, nous attend**ons**, vous attend**ez**, ils attend**ent**
Ebenso: *descendre* (aussteigen, hinuntergehen), *répondre* (antworten), *vendre* (verkaufen), *entendre* (hören).

## 9. Verben im Präsens: unregelmäßig

### Die 4 wichtigsten (unbedingt auswendig)
| | **être** (sein) | **avoir** (haben) | **aller** (gehen/fahren) | **faire** (machen) |
|---|---|---|---|---|
| je | suis | **j'**ai | vais | fais |
| tu | es | as | vas | fais |
| il/elle/on | est | a | va | fait |
| nous | sommes | avons | allons | faisons |
| vous | êtes | avez | allez | **faites** |
| ils/elles | sont | ont | vont | font |

### Modalverben und Wissen
| | **vouloir** (wollen) | **pouvoir** (können/dürfen) | **devoir** (müssen) | **savoir** (wissen/können) |
|---|---|---|---|---|
| je | veux | peux | dois | sais |
| tu | veux | peux | dois | sais |
| il/elle/on | veut | peut | doit | sait |
| nous | voulons | pouvons | devons | savons |
| vous | voulez | pouvez | devez | savez |
| ils/elles | veulent | peuvent | doivent | savent |

### Bewegung und Alltag
| | **venir** (kommen) | **prendre** (nehmen) | **partir** (abfahren) | **sortir** (ausgehen) | **dormir** (schlafen) |
|---|---|---|---|---|---|
| je | viens | prends | pars | sors | dors |
| tu | viens | prends | pars | sors | dors |
| il/elle/on | vient | prend | part | sort | dort |
| nous | venons | prenons | partons | sortons | dormons |
| vous | venez | prenez | partez | sortez | dormez |
| ils/elles | viennent | prennent | partent | sortent | dorment |

wie *venir*: *revenir* (zurückkommen), *devenir* (werden). Wie *prendre*: *apprendre* (lernen), *comprendre* (verstehen).

### Kommunikation und Sinne
| | **dire** (sagen) | **lire** (lesen) | **écrire** (schreiben) | **voir** (sehen) | **connaître** (kennen) |
|---|---|---|---|---|---|
| je | dis | lis | **j'**écris | vois | connais |
| tu | dis | lis | écris | vois | connais |
| il/elle/on | dit | lit | écrit | voit | connaît |
| nous | disons | lisons | écrivons | voyons | connaissons |
| vous | **dites** | lisez | écrivez | voyez | connaissez |
| ils/elles | disent | lisent | écrivent | voient | connaissent |

### Weitere häufige
| | **boire** (trinken) | **mettre** (legen, anziehen) | **ouvrir** (öffnen) |
|---|---|---|---|
| je | bois | mets | **j'**ouvre |
| tu | bois | mets | ouvres |
| il/elle/on | boit | met | ouvre |
| nous | buvons | mettons | ouvrons |
| vous | buvez | mettez | ouvrez |
| ils/elles | boivent | mettent | ouvrent |

*ouvrir* wird wie ein -er-Verb konjugiert (ebenso *offrir* = schenken).

**savoir oder connaître?**
- *savoir* = etwas wissen / können (gelernt): *Je **sais** nager. Je ne **sais** pas.*
- *connaître* = kennen (Personen, Orte): *Je **connais** Paul. Tu **connais** Paris ?*

## 10. Reflexive Verben

Beispiel *se lever* (aufstehen):
| je **me** lève | tu **te** lèves | il/elle **se** lève | nous **nous** levons | vous **vous** levez | ils/elles **se** lèvent |
|---|---|---|---|---|---|

Vor Vokal: *je **m'**appelle, tu **t'**habilles, il **s'**appelle*

Häufige reflexive Verben A1:
| Französisch | Deutsch |
|---|---|
| s'appeler | heißen |
| se lever | aufstehen |
| se réveiller | aufwachen |
| se laver | sich waschen |
| se doucher | duschen |
| s'habiller | sich anziehen |
| se brosser les dents | Zähne putzen |
| se coucher | ins Bett gehen |
| se reposer | sich ausruhen |
| se promener | spazieren gehen |
| s'amuser | Spaß haben |
| se dépêcher | sich beeilen |
| s'asseoir (Assieds-toi / Asseyez-vous) | sich setzen [nur als Wendung] |

- Verneinung: *Je **ne me** lève **pas** tôt.*
- Mit Infinitiv: *Je vais **me** coucher.* (Pronomen passt sich an: *Tu vas **te** coucher.*)
- Passé composé immer mit **être**: *Je **me suis** levé(e) à 7 heures.* [A1/A2]

## 11. Imperativ (Aufforderung)

Drei Formen: **tu**, **nous** (lasst uns), **vous**. Ohne Subjektpronomen.

| Infinitiv | tu | nous | vous |
|---|---|---|---|
| parler | **parle** (ohne -s!) | parlons | parlez |
| écouter | écoute | écoutons | écoutez |
| tourner | tourne | tournons | tournez |
| aller | **va** | allons | allez |
| venir | viens | venons | venez |
| prendre | prends | prenons | prenez |
| faire | fais | faisons | **faites** |
| attendre | attends | attendons | attendez |
| être | **sois** | **soyons** | **soyez** |
| avoir | **aie** | **ayons** | **ayez** |
| s'asseoir | assieds-toi | asseyons-nous | asseyez-vous |
| se lever | lève-toi | levons-nous | levez-vous |

- Verneinung: ***Ne** parle **pas** ! **Ne** fumez **pas** !*
- Höflich mit *s'il vous plaît / s'il te plaît*: *Fermez la porte, s'il vous plaît.*
- Noch höflicher als Frage: *Vous pouvez fermer la porte ?*
- Typische Anweisungen (Prüfung, Unterricht, Wegbeschreibung): *Écoutez. Lisez. Écrivez. Répétez. Cochez la bonne réponse. Complétez. Tournez à gauche. Allez tout droit. Prenez la deuxième rue.*

## 12. Futur proche (nahe Zukunft): aller + Infinitiv

| je **vais** partir | tu **vas** manger | il **va** pleuvoir | nous **allons** visiter | vous **allez** voir | ils **vont** venir |
|---|---|---|---|---|---|

- *Demain, je **vais travailler**.* (Morgen werde ich arbeiten.)
- *Ce week-end, nous **allons faire** du vélo.*
- Verneinung umschließt *aller*: *Je **ne vais pas** venir.*
- Zeitangaben: *demain, après-demain, ce soir, ce week-end, la semaine prochaine, le mois prochain, l'année prochaine, bientôt, dans deux jours*
- Das *futur simple* (je parlerai) ist A2. Für A1 reicht futur proche.

## 13. Passé composé (Vergangenheit) – Ende A1

**Bildung:** *avoir* oder *être* im Präsens + **Partizip**

### Partizip regelmäßig
| Infinitiv auf | Partizip | Beispiel |
|---|---|---|
| -er | **-é** | parler → parl**é**, manger → mang**é** |
| -ir (finir) | **-i** | finir → fin**i**, choisir → chois**i** |
| -re (attendre) | **-u** | attendre → attend**u**, vendre → vend**u** |

### Partizip unregelmäßig (die wichtigsten)
| Infinitiv | Partizip | Infinitiv | Partizip |
|---|---|---|---|
| être | **été** | avoir | **eu** |
| faire | **fait** | prendre | **pris** |
| voir | **vu** | boire | **bu** |
| lire | **lu** | pouvoir | **pu** |
| vouloir | **voulu** | devoir | **dû** |
| savoir | **su** | connaître | **connu** |
| dire | **dit** | écrire | **écrit** |
| mettre | **mis** | ouvrir | **ouvert** |
| venir | **venu** | partir | **parti** |
| sortir | **sorti** | dormir | **dormi** |
| naître | **né** | mourir | **mort** |
| comprendre | **compris** | apprendre | **appris** |

### Mit avoir (die allermeisten Verben)
| j'**ai** mangé | tu **as** mangé | il/elle **a** mangé | nous **avons** mangé | vous **avez** mangé | ils/elles **ont** mangé |
|---|---|---|---|---|---|

*Hier, j'**ai visité** le Louvre. Nous **avons mangé** au restaurant. Tu **as fait** quoi ce week-end ?*

### Mit être (Bewegung/Zustandswechsel + alle reflexiven Verben)
**aller, venir, arriver, partir, entrer, sortir, monter, descendre, naître, mourir, rester, tomber, passer (par), retourner, rentrer, revenir, devenir**
Partizip passt sich an das Subjekt an (wie ein Adjektiv):
| je **suis** allé(e) | tu **es** allé(e) | il **est** allé / elle **est** allée | nous **sommes** allé(e)s | vous **êtes** allé(e)(s) | ils **sont** allés / elles **sont** allées |
|---|---|---|---|---|---|

*Je **suis allée** à Paris. Il **est né** en 1998. Nous **sommes rentrés** tard.*

### Verneinung im passé composé
*ne* + Hilfsverb + *pas* + Partizip: *Je **n'ai pas** mangé. Elle **n'est pas** venue.*

### Typische Zeitangaben
*hier (gestern), avant-hier, hier soir, ce matin, la semaine dernière, le week-end dernier, l'année dernière, il y a deux jours (vor zwei Tagen), en 2020, déjà (schon)*

## 14. Passé récent: venir de + Infinitiv [A1/A2]
= gerade eben etwas getan haben
*Je **viens d'**arriver.* (Ich bin gerade angekommen.) *Il **vient de** partir.* (Er ist gerade gegangen.)

| **savoir** + Inf. | können (gelernt) | *Je **sais** nager.* |

## 16. Verneinung

| Form | Bedeutung | Beispiel |
|---|---|---|
| **ne … pas** | nicht | *Je **ne** parle **pas** chinois.* |
| **ne … pas de** | kein | *Je **n'**ai **pas de** voiture.* |
| **ne … plus** | nicht mehr | *Je **ne** fume **plus**.* |
| **ne … jamais** | nie | *Je **ne** mange **jamais** de viande.* |
| **ne … rien** | nichts | *Je **ne** comprends **rien**.* |
| **ne … personne** | niemand | *Je **ne** connais **personne**.* [A1/A2] |
| **pas du tout** | überhaupt nicht | *Je n'aime **pas du tout** ça.* |
| **non plus** | auch nicht | *Moi **non plus**.* |

- *ne* → *n'* vor Vokal: *Je **n'**aime pas …*
- Stellung: *ne* + konjugiertes Verb + *pas*: *Je **ne** vais **pas** venir. Je **n'**ai **pas** mangé. Je **ne me** lève **pas**.*
- Gesprochen fällt *ne* oft weg: *Je sais pas. C'est pas grave.* (Verstehen ja, in der Prüfung lieber mit *ne*.)
- **Oui / Non / Si:** Auf eine verneinte Frage antwortet man mit **si**, wenn man widerspricht: *Tu n'aimes pas le café ? – **Si**, j'adore le café !*

## 17. Fragen

### Ja/Nein-Fragen: drei Möglichkeiten
| Form | Register | Beispiel |
|---|---|---|
| **Intonation** (Stimme hoch) | gesprochen, locker | *Tu as des enfants ?* |
| **Est-ce que** + Aussagesatz | neutral, immer richtig | ***Est-ce que** tu as des enfants ?* |
| **Inversion** (Verb – Pronomen) | formell, schriftlich | ***As-tu** des enfants ? **Avez-vous** des enfants ?* |

Bei Inversion mit *il/elle/on* und Vokal am Verbende: **-t-** einfügen: *Parle**-t-**il français ? A**-t-**elle un frère ?*

### Fragewörter
| Fragewort | Bedeutung | Beispiel (locker / est-ce que / Inversion) |
|---|---|---|
| **qui** | wer | *Qui est-ce ? C'est qui ?* |
| **que / qu'est-ce que / quoi** | was | *Tu fais **quoi** ? / **Qu'est-ce que** tu fais ? / **Que** fais-tu ?* |
| **qu'est-ce que c'est ?** | was ist das? | *Qu'est-ce que c'est ? – C'est un livre.* |
| **où** | wo, wohin | *Tu habites **où** ? / **Où est-ce que** tu habites ? / **Où** habites-tu ?* |
| **d'où** | woher | *Tu viens **d'où** ? / **D'où** venez-vous ?* |
| **quand** | wann | *Tu pars **quand** ? / **Quand** partez-vous ?* |
| **à quelle heure** | um wie viel Uhr | *Le train part **à quelle heure** ?* |
| **comment** | wie | *Comment tu t'appelles ? / **Comment** vous appelez-vous ? / **Comment** ça va ?* |
| **combien** | wie viel | *C'est **combien** ? / Ça coûte **combien** ?* |
| **combien de** | wie viele | ***Combien de** frères avez-vous ?* |
| **pourquoi** – **parce que** | warum – weil | ***Pourquoi** tu apprends le français ? – **Parce que** j'aime la France.* |
| **quel / quelle / quels / quelles** | welche(r/s) | ***Quel** âge as-tu ? **Quelle** heure est-il ? **Quels** sont tes loisirs ? **Quelle** est ton adresse ?* |

| **de quelle nationalité** | welcher Nationalität | *Vous êtes **de quelle nationalité** ?* |

*quel* richtet sich nach dem Nomen: *quel jour, quelle couleur, quels films, quelles langues*.

## 19. Präsentative: c'est, il y a, voici

| Struktur | Bedeutung | Beispiel |
|---|---|---|
| **C'est** + Sg. / **Ce sont** + Pl. | das ist / das sind | *C'est mon frère. Ce sont mes parents.* |
| **Qui est-ce ? – C'est …** | Wer ist das? | *C'est Marie.* |
| **Qu'est-ce que c'est ? – C'est …** | Was ist das? | *C'est un cadeau.* |
| **C'est** + Adjektiv (Bewertung) | das ist … | *C'est beau ! C'est cher. C'est super.* |
| **Il y a** + Nomen | es gibt / da ist | ***Il y a** un parc près d'ici. **Il n'y a pas de** bus.* |
| **Est-ce qu'il y a … ? / Il y a … ?** | Gibt es …? | *Il y a une pharmacie près d'ici ?* |
| **Voici / Voilà** | hier ist / da ist | ***Voici** mon passeport. **Voilà** votre monnaie.* |

**c'est oder il/elle est?**

- *C'est + un/une + Nomen*: ***C'est un** médecin. **C'est une** Française.*
- *Il/Elle est + Adjektiv* für eine Person: *Elle est sympa.* / *C'est + Adjektiv* für eine Sache oder Situation: *C'est intéressant.*

## 26. Satzbau: Wortstellung im Überblick

| Satztyp | Stellung | Beispiel |
|---|---|---|
| Aussage | Subjekt – Verb – Objekt – Ort – Zeit | *Je mange une pizza au restaurant ce soir.* |

| Verneinung | Subjekt – ne – Verb – pas – … | *Je **ne** mange **pas** de viande.* |
| Zwei Verben | Subjekt – konj. Verb – Infinitiv | *Je **veux** **partir**. Je **vais** **manger**.* |
| Frage mit est-ce que | (Fragewort) – est-ce que – Subjekt – Verb | *Où **est-ce que** tu habites ?* |
| Frage mit Inversion | (Fragewort) – Verb-Subjekt | *Où **habites-tu** ?* |
| Adjektiv | meist nach dem Nomen | *une voiture rouge* |
| Pronomen | vor dem Verb | *Je **le** prends.* |

**Typische Fehler von Deutschsprachigen**
- ~~Ce soir mange je~~ → *Ce soir, je mange.* (kein Verb an Position 2)
- ~~Je suis 25 ans~~ → *J'**ai** 25 ans.*
- ~~Je suis froid~~ → *J'**ai** froid.*
- ~~Je n'ai pas un chien~~ → *Je n'ai pas **de** chien.*
- ~~Je suis un étudiant~~ → *Je suis étudiant.* (Beruf ohne Artikel)
- ~~J'aime chocolat~~ → *J'aime **le** chocolat.*
- ~~Je vais à le cinéma~~ → *Je vais **au** cinéma.*
- ~~Je suis allé en Paris~~ → *Je suis allé **à** Paris.*
